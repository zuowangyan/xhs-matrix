# xhs-matrix · 小红书 AI 矩阵运营系统

> 采集竞品/热点 → AI 分析选题 → 按人设 + 产品知识库原创图文与配图 → 多账号像真人一样自动发布。
> 本地桌面应用（Electron），同源托管前端，支持局域网多人浏览器访问。数据全部存在本机，安全可控。

> ⚠️ 本项目仅供学习交流与合规自用。采集/发布均为真实操作账号，请遵守目标平台规则与相关法律，风险自负。

---

## ✨ 功能特性

- **总控台**：项目制流水线（手动 / 半自动 / 全自动 + 定时），多项目并行、互不影响
- **采集**：用采集号抓关键词/竞品/热点笔记，自动去重、滚动清理、采集冷却（省号防风控）
- **选题分析**：AI 从语料提炼用户痛点 + 候选选题
- **人设 / 知识库**：三层 LLM Wiki（来源/实体/主题），可自动沉淀
- **素材图库**：本地上传 + 局域网文件夹（NAS）按需读取，支持子目录与预览
- **内容生成**：AI 画面扩写配图 / 图库按主题智能匹配 / 每条可手填提示词；AI 图自动去元数据降低被判定概率
- **账号矩阵**：每号独立浏览器指纹、每日上限养号
- **发布日历**：拟人逐字填写、错峰、发布时段；可「人工确认发布」也可全自动
- **模型网关**：OpenAI 兼容 + Gemini，多供应商多模型，支持 Claude 缓存（文本 + 生图统一）
- **运行记录 / 开机自启 / 局域网共享**

## 🧱 技术栈

- 桌面壳：Electron
- 前端：Vue 3 + Element Plus + Vite
- 后端：NestJS + Prisma + SQLite（全局前缀 `api/v1`）
- 浏览器自动化：patchright（隐身 Playwright 分支）
- 中文分词：@node-rs/jieba；图像处理：sharp

## 🚀 使用方法

### 方式一：直接装（推荐普通用户）
下载 Release 里的 **离线安装包 `小红书矩阵_安装包.exe`**，双击安装（已内置 Node 与浏览器，装完即用、无需联网装依赖）。
- 安装到 Program Files，数据存于用户 `AppData`，**重装/更新覆盖不会丢数据**。
- 自动创建桌面图标、放行防火墙（开启局域网共享）。

### 方式二：源码运行（开发者）
```bash
# 后端
cd backend-ts
npm install
npx prisma generate
npx prisma db push          # 建 SQLite 表
cp .env.example .env
npm run start:dev           # http://127.0.0.1:4180

# 前端（/api 自动代理到 4180）
cd ../frontend
npm install
npm run dev                 # http://127.0.0.1:5273

# Electron（先构建前后端）
cd ../frontend && npm run build
cd ../backend-ts && npm run build
cd ../electron && npm install && npm start
```

### 首次配置（4 步）
1. **设置 → 模型网关**：新增供应商，填 baseURL / API Key / 模型（文本 + 生图各一个）。
2. **账号矩阵**：添加采集号（登录主站）、发文号（登录创作平台），各自扫码登录。
3. **人设 / 产品库**：建人设 + 知识库（决定口吻与产品知识）。
4. **总控台**：新建运营项目（或用内置示例「面膜补水种草」），选模式开跑。

### 核心概念
- **模式**：手动（停在选题）/ 半自动（停在草稿，自己发）/ 全自动（自动到发布）。
- **定时自动跑**：是否按间隔无人触发；关掉则只靠「立即跑」。
- 最常用：**半自动 + 定时开** = 每天自动堆好草稿，你只管审核发布。

### 局域网共享
`backend-ts/.env` 设 `LAN_ACCESS=1`，放行防火墙 4180 端口，同一局域网用浏览器访问
`http://<主机IP>:4180` 即可使用同一套界面与数据（安装包默认已开启并自动放行）。
